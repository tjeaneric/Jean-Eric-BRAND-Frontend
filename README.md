# Jean-Eric TUYISHIMIRE - Professional Portfolio

A modern, responsive personal portfolio website for a DevOps & Software Engineer showcasing experience, skills, and projects.

## Overview

This is a professional portfolio built with vanilla HTML, CSS, and JavaScript. It features a clean, modern design with a dark theme optimized for developers and engineers. The site includes smooth scrolling navigation, responsive layout, and professional styling.

## Features

- **Responsive Design**: Mobile-first, works seamlessly on all devices
- **Dark Professional Theme**: Modern color palette with accent colors (neon green & blue)
- **Smooth Navigation**: Scroll-based navigation with active state indicators
- **SEO Optimized**: Meta tags for Open Graph and search engines
- **Fast Loading**: Minimal JavaScript, optimized CSS
- **Professional Typography**: Uses Inter and JetBrains Mono fonts
